# Age rating questionnaire (wifyradar)

Complete the **Age Ratings** questionnaire in [App Store Connect](https://appstoreconnect.apple.com) for **wifyradar**. Completing this doc checks off the age rating item in [`app-store-checklist.md`](app-store-checklist.md) §3.

Apple: [Set an app age rating](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating/).

Recorded answers below are the choices used for this app. Update this file if the questionnaire or the app’s features change.

---

## 1. Open Age Ratings

1. Open [App Store Connect](https://appstoreconnect.apple.com) → **Apps** → **wifyradar**.
2. Left sidebar → **General** → **App Information**.
3. **Age Ratings** → **Set Up Age Ratings** (or **Edit** at the top of App Information if a rating already exists).

**Done when:** the Age Ratings dialog is on **Step 1: Features**.

---

## 2. Step 1: Features

Select whether the app has certain in-app controls and capabilities.

| Item | Answer |

**Next**.

**Done when:** Step 1 is complete and the progress bar advances.
