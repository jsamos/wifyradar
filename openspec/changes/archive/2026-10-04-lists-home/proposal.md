# Proposal: Lists home

## Intent

Replace the splash-only app with a real home: see lists, create one, open it, and add items on a single iPhone — before iCloud sharing.

## Scope

- On launch, land on a **Lists** home (splash-only root goes away)
- Empty state with a way to create the first list
- Create a list with a name
- Show the user’s lists
- Open a list detail (name + items)
- Add a text item to a list
- Lists and items remain available after leaving the screen and after relaunching the app

## Out of scope

- Sharing / invites / second-Apple-ID sync (see **share-list**)
- In-app login
- Push notifications
- Grocery-specific fields, photos, quantities
- Onboarding / tutorial
- Keeping the splash as the only screen (brand MAY remain in nav chrome)
